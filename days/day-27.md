### Session overview

This advanced session builds on the DevOps CI/CD Pipeline Fundamentals session and explores how enterprise-grade pipelines securely move applications from code commit to production. Participants will examine automated testing, artefact management, containerisation, security scanning, environment promotion, production approvals, Kubernetes deployment, workload identity, observability, rollback, performance optimisation, and troubleshooting. Completion of, or attendance at, the DevOps CI/CD Pipeline Fundamentals session is a prerequisite.
