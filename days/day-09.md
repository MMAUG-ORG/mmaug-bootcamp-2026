### Session overview

As part of the MMAUG 30-Day AI and DevOps Fundamentals Bootcamp, this beginner-friendly session will introduce participants to the core concepts of Git and GitHub and their role in modern AI application development. We will explore repositories, commits, branches, pull requests, collaboration, and source control, while demonstrating how GitHub supports the end-to-end DevOps lifecycle. By the end of the session, participants will understand how to confidently use Git and GitHub to manage, track, collaborate on, and deploy AI application projects.
