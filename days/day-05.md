### Session overview

Fundamentals of DevOps CI/CD Pipelines introduces participants to the automated processes used to build, test and deliver software reliably. The session explains how Continuous Integration validates every code change, while Continuous Delivery and Continuous Deployment move verified application artefacts safely through different environments and into production.
