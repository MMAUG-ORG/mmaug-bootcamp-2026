### Session overview

This session gives complete beginners a mental map of Microsoft Azure before they ever open the portal. Rather than diving into any single service, we look at the core categories every cloud platform needs: where code runs (compute), where data lives (storage), how users and apps prove who they are (Microsoft Entra ID), how systems talk to each other (networking), how teams see what's happening (monitoring), and how Azure AI services fit into that picture. Using a simple AI app idea as a running example, participants will practice mapping each part of their idea to the Azure category responsible for it, building the vocabulary and mental model needed before touching real infrastructure. No Azure account or prior cloud experience required, this is a conceptual session designed to make later hands-on labs easier to follow.
