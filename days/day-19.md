### Session overview

Automating Azure DevOps workflows with Foundry models means using intelligent, agent‑driven capabilities from Microsoft Foundry to streamline processes, reduce manual effort, and enable adaptive decision‑making across Azure DevOps. The core automation features come from Foundry’s AI models, which can reason about tasks, trigger actions, and interact with Azure DevOps services.

Foundry models provide autonomous execution, event‑driven reasoning, and tool‑based actions, allowing them to update systems without custom integration code.
