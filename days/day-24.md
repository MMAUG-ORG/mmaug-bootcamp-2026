### Session overview

Agentic AI often gets sold as "the agent does everything", with little explanation of what's actually happening, or where it can go wrong. This session shows a simple, human-supervised pattern anyone can use: turning a vague request ("I need an app that does X") into a clear specification, with an AI agent proposing and a human reviewing at each step. Using a live, tool-agnostic example, attendees will see where the agent gets it right, where it doesn't, and why keeping a human in the loop is what makes the workflow trustworthy not just a formality.

Learning outcome:
Attendees will be able to structure a human-in-the-loop review process around an AI agent to convert an ambiguous request into a clear, actionable specification document.

What attendees will take away:

A simple, reusable "propose → review → approve" pattern for working with AI agents
A checklist of things to check before trusting an agent's output
Awareness of common failure modes and how human review catches them

Prerequisites:
None. No coding experience required. A free-tier AI assistant account is helpful but not required to follow along.
