### Session overview

Ever lost your work, struggled to collaborate with teammates, or wondered how open-source software is built? The answer lies in version control. This hands-on session demystifies the essential tools used by developers worldwide: Git and GitHub. We'll start with the "why"—understanding version control through simple, real-life analogies. Then, we'll dive into the "how" with a step-by-step guide to using Git commands for your own projects. Finally, we'll bring it all together on GitHub, where you'll learn the complete workflow for collaborating on a project and make your very first open-source contribution in real-time. Leave this session with the confidence and skills to manage your code like a pro.
Target Audience: Absolute beginners, students, self-taught developers, designers, writers, or anyone who wants to understand and use the industry-standard tools for project collaboration. No prior experience with Git is required.
