## 🎯 Learning Objectives
By completing this session and hands-on lab, learners will be able to:
1. **Understand Distributed Version Control:** Learn content tracking, history preservation, and agility in software development.
2. **Master Local Git Workflow:** Navigate the 3 stages—Working Directory, Staging Area, and Local Repository.
3. **Collaborate with GitHub:** Connect local repositories to GitHub remotes (`git push`, `git pull`).
4. **Branch & Resolve Conflicts:** Work in feature branches, open Pull Requests (PRs), and resolve merge conflicts in VS Code or GitHub.
