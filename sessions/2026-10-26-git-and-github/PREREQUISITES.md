# Prerequisites & Setup Instructions

## 1. Prerequisites
- **Hardware:** macOS, Windows, or Linux laptop.
- **Accounts:** A free [GitHub Account](https://github.com/signup).

## 2. Required Software
1. **Git CLI:** Download and install from [git-scm.com](https://git-scm.com/downloads).
2. **Code Editor:** Install [Visual Studio Code](https://code.visualstudio.com/).

## 3. Initial Configuration
Open terminal / Git Bash and configure your identity:

```bash
git --version
git config --global user.name "Your Name or Handle"
git config --global user.email "your.email@example.com"
```
