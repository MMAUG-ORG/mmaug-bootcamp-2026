## Minimum lab repository checklist

Each public speaker repository should contain:

- a clear README and learning objectives;
- prerequisites and setup instructions;
- step-by-step lab instructions;
- sample code, templates, prompts, or other learner files;
- cleanup instructions where cloud resources can incur cost; and
- a license or reuse statement for the published materials.

Do not add a repository link to this schedule until it opens without authentication and the content review is complete.
